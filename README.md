PyFast-ADT is a python package to automate 3D Electron Diffraction (3DED) data acquisition for custom Electron Microscope setups.
PyFast-ADT is able to collect 3DED data in continuous (cRED)
and in stepwise (PEDT) modes, both available for parallel and
quasi parallel illumination.

On top of that, the software is well known in the community to be able to perform **"a priori" crystal tracking** during
the data acquisition, using the technique of beam shift. 

In this way, challenging nano-crystals can be measured using a
relatively small electron probe size.

PyFast-ADT is tested on python 3.9.7 both 32 and 64 bit. 

checkout the [docs here!](https://pyfast-adt.readthedocs.io/en/dev)
